## 🚀 Key Features Matrix
- 🏠 Home Page & Discovery (Hero banner, department grid, featured & new arrivals)
- 🔍 Catalog, Search & Filtering (Live keyword search, price range filter, sorting, pagination)
- 📦 Product Details (HD image gallery, inventory stock badges, quantity adjuster, related items)
- 🛒 Shopping Cart (LocalStorage persistence, subtotal, 8% tax calculation, free shipping waiver)
- 🔐 User Authentication (Bcryptjs hashing, JWT 30-day tokens, 1-Click demo logins for evaluators)
- 💳 Checkout & Payment (Server-side price verification, Stripe test mode, safe test simulator)
- 🛡️ Admin Control Center (Live business KPIs, Product CRUD modals, Order fulfillment updater)
